# 论文阅读记录

围绕具体研究问题阅读文献，保留方法、证据与可复现信息。目前本页提供阅读框架，具体论文笔记待整理。

## 三遍阅读路线

1. **判断相关性**：阅读摘要、问题定义与结论，明确它解决什么问题。
2. **理解方法**：梳理输入、输出、关键假设和方法结构。
3. **检查证据**：阅读实验设置、基线、消融与失败案例。

## 单篇论文记录模板

| 字段 | 要记录的内容 |
| --- | --- |
| 基本信息 | 标题、作者、年份、原文与代码入口 |
| 研究问题 | 场景、目标以及现有方法的不足 |
| 核心方法 | 输入输出、关键步骤与必要假设 |
| 实验证据 | 数据、指标、基线与主要结果 |
| 方法局限 | 失败条件、成本与适用范围 |
| 复现条件 | 依赖、硬件、参数与数据获取方式 |
| 研究启发 | 与智能放牧任务的联系及下一步实验 |

## 阅读后的三个问题

- 方法的改进来自哪里，是否有消融实验支持？
- 实验条件与自己的任务有哪些差异？
- 可以通过哪个最小实验验证自己的理解？
