# 第二部分：公式讲解

公式是把“怎么利用反馈更新决策”写得更精确。先统一符号，再对照每个算法的数字例子。


## 看图梳理

[打开大图](../../assets/learning/rl-math-index.svg)

**先找已知量**：状态、动作、奖励，折扣、步长、终止标记；**再找目标量**：回报、价值或优势，目标与估计的差距；**最后看更新**：谁是待优化参数，方向与梯度是否匹配。


## 公共符号

### 看到长公式，先把它拆成四个问题

1. **输入是什么？** 当前状态、动作、奖励与下一状态，哪些来自观察，哪些是暂时估计？
2. **要算哪个目标？** 先算奖励加未来估计，还是先把整局奖励加起来？
3. **现在估了多少？** 找当前 V 或 Q，不要把它与目标混在一起。
4. **怎么改？** 表格直接改一格；网络通过损失与梯度改变参数。

第一次阅读可以先跳过求和号和下标，用每页的一个数字例子走完这四步，再回来对照精确公式。

### 网络、参数、损失、梯度，分别是什么

**网络**可以先当作“输入数字，输出预测”的函数；**参数**是这个函数内部能调整的数字。最简单的类比是预测函数 y = w × x：输入 x 固定，调 w 就能改变预测。真实神经网络更复杂，但仍然是输入、参数与输出的关系。

**损失**给预测错误打分。例如目标 3、预测 1，平方误差为 (1−3)² = 4；预测改为 2，损失为 1；预测恰好 3，损失为 0。损失变小只说明更接近当前训练目标，不自动证明机器人任务表现更好。

**梯度**描述参数小幅变化时，目标或损失怎样变化。单个参数可以想成斜坡的坡度：梯度下降朝降低损失的方向走，梯度上升朝提高目标的方向走。步子太大可能越过合适位置；“梯度指方向”不意味着一步走到最优。

### 概率与平均：这些符号不用靠背

有两个可能结果，概率分别是 0.25 和 0.75，分数分别是 0 和 1，则期望为 0.25 × 0 + 0.75 × 1 = 0.75。期望不是最幸运结果 1，也不是不加权的平均 0.5。

`Σ` 表示按规定把多项相加，`E` 表示按概率求平均；用一批实际样本计算时，常用样本均值近似这个平均。批次就是一次拿来更新的一组记录；不是完整的一局，也不是一种新的状态。

log 是自然对数，例如 log(1) = 0，log(小于 1 的正数) 为负。策略公式用 log 概率的梯度，是为了表达概率怎样随参数改变；初学先看每页的梯度项与数字例子，不必先完整推导对数函数。连续动作时出现的是密度，密度可能大于 1，因此对数也可能为正。

下面的符号表用于查询，不要求一口气背完。各算法页继续说明哪些量要更新、哪些量在这次更新里保持固定。

| 符号 | 含义 |
| --- | --- |
| $s_t, a_t$ | 时间 $t$ 的状态与动作 |
| $r_{t+1}$ | 执行动作后收到的奖励 |
| $\pi(a\mid s)$ | 在状态 $s$ 选择动作 $a$ 的概率；连续动作时为密度 |
| $\gamma$ | 折扣因子，控制未来奖励的权重 |
| $G_t$ | 从当前时刻开始的折扣回报 |
| $V(s)$ | 按某套策略，从状态 $s$ 出发的预期回报 |
| $Q(s,a)$ | 先做动作 $a$，再按某套策略行动的预期回报 |
| $\alpha,\eta$ | 学习率，控制参数改变的步幅 |
| $\theta,\phi$ | 策略或价值网络的参数，具体含义见各页 |
| $d$ | 真正终止标记；终止为 1，其他为 0 |
| $B,\mathcal D$ | 一批样本的数量与经验回放数据集 |
| $\mathbb E,\sum$ | 按概率求平均与把指定项相加 |
| $\nabla$ | 梯度，表示参数朝哪个方向改变会让函数上升 |
| $\max,\arg\max$ | 最大分数与取得最大分数的动作 |
| $\bar\theta,\bar\phi$ | 更新较慢的目标网络参数 |

## 常见运算怎么读

`clip(x, lower, upper)` 把数值限制在上下界内；`min` 取较小值。`stopgrad` 表示这项在当前梯度计算中视为常量。损失页中的平均通常用一批样本代替总体平均。

折扣通常取 $0\leq\gamma<1$；有限回合任务也可以取 1，但需要回报有良好定义。表格页里的学习率 $\alpha$ 与 SAC 常用同名温度不是同一概念，本栏目用 $\beta$ 表示 SAC 温度。

## 回报不等于即时奖励

$$
G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+\cdots
$$

例如未来奖励为 1、2、3，$\gamma=0.9$，则回报为 $1+0.9\times2+0.81\times3=5.23$。折扣不是奖励的发生概率，而是目标中对时间的加权。

## 价值不等于一次真实结果

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s],\qquad
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a]
$$

$\mathbb E$ 表示平均意义上的预期。一次轨迹可能运气很好或很差，所以一次回报与价值估计不必相等。

## 更新、目标和损失

表格更新经常写成：

$$
\text{新估计}=\text{旧估计}+\text{学习率}\times(\text{目标}-\text{旧估计})
$$

神经网络通常通过最小化损失间接更新参数。策略优化常写成最大化收益目标；代码若使用梯度下降，通常把目标取负号作为损失。

## 终止与截断 { #termination-and-truncation }

真正终止后没有后续回报，故使用 $(1-d)$ 去掉自举项。仅因外部时间限制而截断时，通常还需要下一状态价值，并在重置前保留最终观测。如果时间本身就是有限时域任务的组成部分，需要把剩余时间与终止定义一起考虑。
