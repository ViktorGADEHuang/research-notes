## 示例背景

**语言：Python 3.12 或以上；依赖：仅标准库；实现方式：手写更新。**

环境是一条走廊：非终止状态为 1～5，起点为 3，左端 0 奖励 −1，右端 6 奖励 +1，中间每步奖励 −0.01。动作 0 向左，动作 1 向右。这是帮助理解算法的小环境，不是羊群仿真。


本页只提供带注释的代码，按步骤阅读即可，无需创建环境或执行脚本。

## 用四行核心运算跟踪一个格子

```python
# 这些是用于讲解的一条已观察经验，以及更新前的两个预测。
current, next_value = 0.3, 0.8
reward, gamma, alpha = -0.01, 0.95, 0.1
terminated = False
future = 0.0 if terminated else gamma * next_value  # 未终止，未来部分 0.76。
target = reward + future                           # 参考目标 0.75。
error = target - current                           # 比旧预测高 0.45。
current += alpha * error                           # 只提高 0.045，变为 0.345。
```

`x += y` 与 `x = x + y` 是这里的同一种加法写法。完整代码不是更新名为 current 的独立变量，而是直接更新 `values[s]`。

| 执行到这里 | s | ns | values 中发生什么 |
| --- | --- | --- | --- |
| `s = 3` | 当前在 3 | 尚未取得 | 不改表 |
| `step(s, a)` 后 | 仍是 3 | 假设为 4 | 返回经历，不自动改 V |
| V 更新后 | 仍是 3 | 仍是 4 | 只修正 values[3] |
| `s = ns` 后 | 变成 4 | 仍记录刚才的 4 | 准备下一步，不再更新旧状态 |

所以 `s = ns` 放在更新之后。若提前覆盖 s，再用 `values[s]` 更新，改到的就是下一位置，公式含义变了。每局起点重新设成 3，但价值表在局外创建，不会每局归零。

## 完整代码

```python title="td · 完整学习代码"
"""标准库教学代码：对照注释理解更新过程，无需运行。"""
import random

# 固定随机数起点，便于对照不同步骤；随机种子不保证跨硬件完全一致。
rng = random.Random(7)
# gamma 给未来奖励打折；alpha 决定每次向目标修正多少。
gamma, alpha = 0.95, 0.1

# 小走廊模型：输入当前位置与动作，返回下一位置、奖励、终止标记。
def step(state, action):
    # 调用者只传动作 0 或 1；先按动作找到下一位置。
    if action == 1:
        ns = state + 1  # 向右。
    else:
        ns = state - 1  # 向左。
    # 两端才是真正终点；0、6 不再作为下一次 step 的输入。
    done = ns in (0, 6)
    # 奖励描述刚发生的结果；进入终点时不再额外扣中间步进代价。
    if ns == 6:
        reward = 1.0
    elif ns == 0:
        reward = -1.0
    else:
        reward = -0.01
    return ns, reward, done


# V 表按状态存分数；两个终止位置也占位，但不更新它们。
# 下标就是状态编号；0 与 6 作为终点占位，非终止位置是 1 到 5。
values = [0.0] * 7
# 采集 10000 个回合；每走一步就修正一次 V，策略始终随机。
# 这些数量是教学设置，不构成收敛保证。
for _ in range(10000):
    # 每一局从位置 3 重新出发；外面的 V/Q 表不重置，所以能积累经验。
    s = 3
    # 持续与环境交互，直到走到左端或右端。
    while s not in (0, 6):
        a = rng.randrange(2)  # 与 MC 使用同一随机策略
        # 执行一次动作，获得下一状态、奖励和真正终止的标记。
        ns, reward, done = step(s, a)
        # 目标 = 本步奖励 + 折扣后的后续估计；done 时后续项归零。
        target = reward + (0.0 if done else gamma * values[ns])
        # TD 每走一步就更新 V，无需等到这一幕结束。
        values[s] += alpha * (target - values[s])
        # 本步更新完以后，再移动当前位置；提前赋值会把旧状态的信息丢掉。
        s = ns
print("Random-policy values:", [round(x, 3) for x in values[1:6]])
```

## 对照公式看代码

`target` 使用下一状态旧价值；`alpha` 控制更新幅度；真正终止时未来项为零。

## 如何理解输出

输出和 MC 评估页相同的左右各半策略的价值，而不是要求它学会永远向右。每步代价会影响中间位置的平均回报；固定学习率又让近期样本持续影响估计，因此最后一张表仍可能波动。

MC 用 1/次数算普通样本平均，本页 TD 固定 alpha=0.1，两者有限采样下不必逐格相等。表格朝合理目标学习，不意味着仅看最后一次打印就能证明已经收敛。

**按这几步做**：

1. 未终止时依次算未来项、目标、误差和新值。
2. 假设仅为外部时间截断，是否自动把未来项清零？
3. 判断 s = ns 应在本次 values[s] 更新前还是之后。

??? tip "先要一点提示？"

    给每个数写上名字，区分奖励、旧预测、目标、参数或动作。每算完一步，把中间结果写下来，再进入下一步，不只抄最后答案。

??? example "对照完整推理"

    未来项 0.95×0.8=0.76；目标 −0.01+0.76=0.75；误差 0.75−0.3=0.45；新 values[3]=0.3+0.1×0.45=0.345。values[4] 是参考，本条更新不改它。

    外部截断不自动等于真正终止，通常仍根据最终观测自举；要看任务如何定义。s = ns 放在本次更新之后，否则更新 values[s] 时 s 已变成 4，就写错了格子。
