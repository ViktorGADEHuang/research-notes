## 一篇项目教程应当读出什么

先找到**输入**：数据由谁提供，名称、形状、单位和时间如何约定。再找到**处理**：函数具体执行了什么，失败分支在哪里。最后找到**输出**：结果交给谁，是否可能缺失，是否共享原数据。

每次记录对应的提交和文件路径。读过源码、编译过独立例子、运行过完整工程是不同的验证范围，笔记里分别写清楚，避免把一个小例子当成项目已经复现。

这个栏目用于完整的项目配套学习；[开源资料目录](../index.md)用于按问题查找外部资料。后续项目也可以按同样的阅读方式加入，不把项目教程堆进通用知识章节中。
